
# Requisitos

Antes de rodar o projeto, instale:

- Java 21
- Git/Github desktop
- PostgreSQL 16
- Postman (pra testes)
- IntelliJ

Também é necessário ter **um banco PostgreSQL já criado** para o projeto.

---

A aplicação irá iniciar em:

```
http://localhost:8080
```

---

# Testando a API com Postman

1. Abra o **Postman**
2. Crie uma nova requisição
3. Use a URL base:

```
http://localhost:8080
```
---

# Uso de Git e GitHub

## Atualizar o projeto

Antes de começar a trabalhar:

```bash
git pull
```
---

# Observações

- O PostgreSQL precisa estar **rodando antes de iniciar a aplicação**.
- A conexão com o banco é configurada no arquivo:

```
src/main/resources/application.properties
```
