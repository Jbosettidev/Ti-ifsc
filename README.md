
# Requisitos

Antes de rodar o projeto, instale:

- Java 21
- Git ou Github desktop
- PostgreSQL 16
- Postman (pra testes)

Também é necessário ter **um banco PostgreSQL já criado** para o projeto.

---

A aplicação irá iniciar em:

```
http://localhost:8080
```

---

# Atualizar o projeto

Antes de começar a trabalhar:

```bash
git pull
```
